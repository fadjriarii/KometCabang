# Security Policy

## Supported Versions

Currently, the KOMET (Academic Analytics & Institutional Intelligence Dashboard) project only provides security updates for the current major release.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Maintaining the security and integrity of institutional data is a top priority. If you discover a security vulnerability within the KOMET application, **please do not create a public GitHub Issue**.

Instead, report your findings privately by sending an email to: **qa.intern@i3l.ac.id**.

To help address the issue quickly and efficiently, please include the following details in your email:
* A clear description of the vulnerability and its potential impact.
* Step-by-step instructions to reproduce the issue.
* Any relevant environment details (e.g., browser version, operating system).
* (Optional) Proposed remediation or patch.

### What to Expect
* **Acknowledgment:** You will receive a response acknowledging receipt of your vulnerability report within 48 hours.
* **Triage:** The report will be investigated and validated against the current codebase.
* **Resolution:** If the vulnerability is confirmed, a security patch will be prioritized, developed, and deployed before any public disclosure is made.
